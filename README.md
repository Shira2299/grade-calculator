# 🧮 מחשבון ציונים – ציון סופי בקורס וממוצע לתואר

כלי קטן וללא צורך בהתקנה לחישוב ציון סופי בקורס (לפי משקל מטלות ומבחן) ולחישוב ממוצע משוקלל לתואר (לפי נקודות זכות). כל הנתונים נשמרים מקומית בדפדפן — שום דבר לא נשלח לשרת.

**🔗 דף חי:** _(הוסיפי כאן את הקישור אחרי הפעלת GitHub Pages, למשל `https://USERNAME.github.io/REPO-NAME/`)_

## ✨ מה זה עושה

**ציון סופי בקורס**
- מזינים משקל וציון למבחן ולכל מטלה (כמות בלתי מוגבלת של מטלות).
- ברגע שסך המשקלים מגיע ל־100, הציון הסופי מחושב ומעוגל לפי עיגול רגיל (0.5 ומעלה כלפי מעלה).
- **מחשבון יעד** — מזינים ציון סופי רצוי, והכלי מחשב איזה ציון צריך לקבל במבחן כדי להגיע אליו (בהינתן שכל שאר המטלות כבר קיבלו ציון).
- אפשר לנהל כמה קורסים במקביל בלשוניות, ולשנות את שם הקורס בלחיצה נוספת על הלשונית הפעילה.

**ממוצע לתואר**
- מוסיפים קורסים עם נקודות זכות (נ"ז), ציון, וסימון "רגיל" / "מתקדם".
- הממוצע מחושב כממוצע משוקלל לפי נ"ז, כאשר קורסי "מתקדם" נספרים פי 1.5 בנ"ז.
  > ⚠️ המכפיל של פי 1.5 הוא הנחה מקובלת ולא כלל שאומת מול גורם רשמי באוניברסיטה הפתוחה. אם יש בתוכנית הלימודים שלך כלל חישוב רשמי שונה, כדאי לוודא מול המדריך לתלמיד ולעדכן את הנוסחה בקובץ.

**ייצוא לאקסל**
- כפתור "ייצוא הנתונים לאקסל" מוריד קובץ CSV מסודר עם כל הקורסים, המטלות, הציונים והממוצעים — נפתח ישירות באקסל עם תמיכה מלאה בעברית.

**הוספה למסך הבית (PWA)**
- לאחר שהדף חי ב-GitHub Pages, אפשר להוסיף אותו למסך הבית בטלפון ולפתוח אותו כמו אפליקציה רגילה — במסך מלא, בלי שורת הכתובת של הדפדפן:
  - **אנדרואיד / כרום:** נכנסים לדף → תפריט שלוש הנקודות → "התקן אפליקציה" / "הוסף למסך הבית".
  - **אייפון / ספארי:** נכנסים לדף → כפתור השיתוף (הריבוע עם החץ) → "הוסף למסך הבית".

## 🚀 איך מריצים

**מקומית:** פותחים את `index.html` בכל דפדפן — אין צורך בשרת, בבנייה (build) או בהתקנת תלויות. (התכונה של "הוספה למסך הבית" דורשת שהדף יהיה מוגש דרך HTTPS אמיתי — היא לא תעבוד בפתיחה ישירה של הקובץ מהמחשב, רק אחרי פרסום ב-GitHub Pages.)

**פרסום ב-GitHub Pages:**
1. יוצרים ריפוזיטורי חדש ב-GitHub ומעלים אליו את **כל הקבצים** מהתיקייה: `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, ו-`README.md` (חשוב שכולם יישארו יחד באותה תיקייה, כדי שהקישורים ביניהם יעבדו).
2. נכנסים ל-**Settings → Pages**.
3. תחת **Source** בוחרים את הענף `main` והתיקייה `/ (root)`, ושומרים.
4. אחרי דקה־שתיים GitHub ייתן קישור בפורמט `https://USERNAME.github.io/REPO-NAME/` — זהו הדף החי.

## 🛠️ טכנולוגיה

HTML, CSS ו-JavaScript רגיל (ללא framework, ללא build step). גופן הכותרות והספרות הוא [Inter](https://fonts.google.com/specimen/Inter) מ-Google Fonts; טקסט עברי מוצג בגופן המערכת. הנתונים נשמרים ב-`localStorage` של הדפדפן בלבד, ולכן הם ספציפיים למכשיר ולדפדפן שבו ממלאים אותם.
